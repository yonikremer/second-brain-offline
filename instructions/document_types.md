# Document Type Classification Instructions

Classify the document type into one of the allowed categories.

## Allowed Document Types

1. **concept**
   - Focus: A single, atomic concept, technology, or theoretical thesis. Usually short, dense, and structured around a main thesis.
   
2. **source-summary**
   - Focus: Summarizing a third-party article, research paper, blog post, or lecture. Contains metadata like authors, source URLs, publication dates, and key claims.

3. **analysis**
   - Focus: Synthesis of multiple ideas, comparative analysis of different models/methods, or structural review of a domain.

4. **technical-specification**
   - Focus: System design, database schemas, CLI specifications, or API design templates.

5. **other**
   - Focus: Any document that does not fit clean definitions above.

## Output Format
Return ONLY the matched document type name (in lowercase) from the list above. Do not output any other text or reasoning.
