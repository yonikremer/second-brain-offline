# Data Sources

Registry of documented data sources in the vault.
Each source lives in its own bundle under `wiki/data-sources/<source-name>/`.

## Bundle convention

A valid data-source bundle contains:

1. `overview.md` — general description, use cases, limits, and maintainer.
2. `connect.py` — connection snippet with a docstring/comment header.
3. `tables.md` — conceptual guide to the source’s tables.
4. `tables/*.md` — one note per table.

Template to copy: `templates/data-source/`.
