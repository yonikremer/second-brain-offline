# APIs

Registry of documented APIs in the vault.
Each API lives in its own bundle under `wiki/apis/<api-name>/`.

## Bundle convention

A valid API bundle contains:

1. `overview.md` — general description, use cases, limits, and maintainer.
2. `auth.py` — authentication snippet with a docstring/comment header.
3. `endpoints.md` — conceptual guide to the API's endpoints.
4. `endpoints/*.md` — one note per endpoint.

Template to copy: `templates/api/`.
